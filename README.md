# Enfermería de Bolsillo

App móvil de apoyo para el personal de enfermería de planta: calculadora de dosis y perfusiones, escalas de valoración, guía de curas y tareas del turno. Funciona sin conexión.

Proyecto intermodular del ciclo de Desarrollo de Aplicaciones Multiplataforma.

**Estado:** en desarrollo.

**Tecnologías:** React Native, SQLite, Node.js, Express y PostgreSQL.
